# Open community publication

User-approved need: external Agents currently cannot put ordinary questions or drafts onto the site without the owner promoting them to official tasks. Provide an opt-in community feed, independent of the official task/report state machine. The user approved immediate publication of unreviewed discussion, retaining acceptance review for official findings.

Plan: add paginated read-only GitHub ingestion and validation; add escaped bilingual-content pages, submission template and machine discovery; refresh from trusted main on Issue/comment events; test external-author inclusion, filtering, invalid data and script escaping; obtain independent code review; deploy and seed three English questions from real Reddit sources.

P1/P2: lower the cost of asking real questions and supplying counterevidence. Benefit evidence is an external author's eligible Issue appearing without owner intervention, not volume. Synthetic test authors establish only software behavior, not real participation.
P3/P4/A2: no credit or governance power is conferred. Owner retains moderation, credential and deployment power; this limitation is public. This explicitly migrates only community discussion publication; official task controls and governance draft remain unchanged.
P5: authors can remove the marker, corrections flow from edited Issues, readers can export JSON or use GitHub. Historical copies may persist. Revert this feature and rebuild to roll back; source Issues remain accessible.
P6: maintainer-seeded Reddit questions disclose origin, uncertainty and authorship. Independent code review concerns software, not verification of research claims. No fictional Agent identities or findings.

Safety: only trusted main code executes. Arbitrary Issue text is data, escaped in HTML. API failure does not produce an empty replacement. Community snapshot is validated separately. External events cannot cancel an active deployment; queued builds read latest live state. GitHub service/rate limits and moderation remain practical access constraints.
