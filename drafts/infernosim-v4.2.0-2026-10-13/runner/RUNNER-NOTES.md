# Runner evidence notes

Source: InfernoSIM v4.2.0, peeled commit `f26b5522bbb20f2904d7534b879fa2896bdf1302`. This is a synthetic retry fixture; no live payment/refund service, credentials or model was used.

The canonical campaign uses the upstream `agent causal discover` and `agent explore` commands with the original `examples/concurrencylab/app.py` unchanged. It runs only the retry scenario: seed 7100; 15 bounded causal schedules; four fault sets (none, noise, response-lost, noise plus response-lost); safe and unsafe clients; 120 executions. The full five-scenario causalbenchmark, minimization and soak were not run.

`campaigns/*/command.json` preserves exact argv and the explicit clean environment. Temporary absolute `/tmp` paths must be changed on another machine. The toolchain was downloaded from Google's official golang.google.cn Go mirror after go.dev TLS failed. The archive matches the official listed SHA256. Modules were fetched using goproxy.cn with the original go.sum and `-mod=readonly`; `go mod verify` succeeded. There was an earlier module-verification attempt without network permission that failed to resolve the proxy; the later successful command is included.

The backup hook reads and backs up real SQLite before the runner deletes its state directory, preserves the JSONL file, then delegates to the original upstream `--check`. It does not alter application logic or assertion values. The final hook labels evidence by `INFERNOSIM_CASE_ID`; the first successful 120-execution campaign had identical counts but less traceable temporary-directory names, so it was rerun for canonical evidence capture. These repeats are not additional independent samples.

For each mode and loss/no-loss condition, `representatives` includes the same causal schedule and exact trial ID, result, actual SQLite backup, SQL table rows, JSONL, and original checker stdout/stderr/exit. `summary.json` was generated by opening all 120 canonical SQLite backups directly, separately from the simulator's effect ledger. Other raw backups remain local.

`unsuitable-ordinary-run` retains an initial failed attempt using ordinary `agent run`. All four processes exited with `response correlation changed`. The fixture generates random JSON-RPC IDs and requires the causal path's runtime-ID remapping. Those attempts are not successful reproductions; the fixture was not patched to bypass the check.

The simulator's `remote-once` assertion is a model/ledger assertion about a synthetic refund effect, not evidence that a real external refund happened once. The SQLite outbox evidence is independently queried local application state. JSONL is a separate storage artifact written by the same outbox function, not a separately designed business oracle. The extra checker is another session under the same operator, not independent outside-community participation. Runner cross-check opened all 120 checker databases and confirmed their reported row distributions.

## Re-execution recipe

Check out the upstream repository at the full commit above into `/tmp/arc-inferno-source-20261013`. Create `/tmp/arc-inferno-runner-20261013` and place the supplied `run.py`, `check_identified.py` and `explore_identified.py` there. Use Go 1.26.9 or the exact verified archive recorded in `go-checksum.json`; on this host it was extracted to that runner directory. Run the exact build argv in `provenance/build/command.json`, preserving `-mod=readonly`; the wrapper supplies a clean environment. Initialize the incident using `provenance/init/command.json`, then discover its graph using `provenance/graph/command.json`. Finally run `python3 /tmp/arc-inferno-runner-20261013/explore_identified.py`. All output directories must be new. This is a controlled loopback execution and requires the host to permit local listeners. The unsafe exploration exits 1 for the expected assertion failure, while its application processes exit 0. See `campaigns/*/command.json` for every exploration flag rather than relying on CLI defaults.

The source-and-binary file records a clean source checkout, source file hashes and the actual compiled binary SHA256. The downloaded Go archive and compiled binary are not bundled in the public evidence packet.
