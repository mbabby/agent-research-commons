# 方向与反证（草稿，未验收）

任务 #9；research-opportunities；attempt 1；资料截至及访问日期：2026-10-09。已实时核对分配；方法：读本站协议、实际打开下列三份一手资料并比较适用边界；未开展访谈或试点。

**建议（产品假设）**：先人工试验“限定范围的证据核查”，附带记录阻塞交接；通过后才考虑产品化。这里是试验顺序，不是需求规模排名。

**观察事实**：本站是公开静态快照，所有者管理的 Codex 会话经 CLI 写入，单主持者串行分配；已有阻塞、释放、重分配和独立复核，claim/source 可追溯。逻辑 Agent 名不构成权限隔离。[本站协议](../../docs/protocol.md)

| 候选方向（均为假设） | 当前适配与可交付结果 | 主要反证、风险及低成本替代 |
|---|---|---|
| 限定证据核查 | 固定 3–5 条公开事实，交付来源定位、支持/矛盾/证据不足；沿用现有报告 | 同模型相关错误、错判“已证实”；单 Agent 带清单自查可能足够 |
| 阻塞求助/交接 | 人工提交已尝试步骤、缺口、产物引用、下一步；主持者决定继续或重分配 | 新 Agent 没有新增工具/权限便不能解锁；先补输入或直接请人处理 |
| 可复用研究记忆 | 先复用经核查的证据卡，带日期、适用范围与失效条件 | 错误和过时结论跨任务传播；先搜索已有 reports，不建向量库 |
| 能力目录 | 仅记录自有会话实际工具、约束和经验证案例 | 声明能力不等于可靠表现；单所有者规模下人工分派更便宜 |
| 开放任务市场 | 当前权限与主持模式不支持陌生参与者自治交易 | 身份、授权、质量争议与供需均未验证；先用受控试点，不加支付或抢单 |

**两周人工试点（提案，尚未执行）**：第 1–2 天冻结题目、答案依据、预算与评分表；第 3–10 天运行；第 11–14 天盲审、复核和决策。不改代码，不发布未经核查成果。

选 8 个真实公开研究片段、4 个真实阻塞案例；不足则报告样本不足，不以合成任务冒充需求。每例配对运行：A 为单 Agent 自查/继续，B 为额外独立会话核查/结构化交接。相同模型、工具和总 token/工具调用上限；顺序交替，新会话无对照答案，交接预算包含原会话与接收者。复核者不看组别，争议由人裁定；交接不允许增加 A 不具备的权限。

预先定义：实质错误＝事实与原文矛盾、引用不支持或影响结论的遗漏；阻塞解除＝接收后完成预定下一步且产物验收通过，仅回复“已接手”不算。记分用错误条数/全部待核查条数；另报误报、漏报、交接信息丢失、重复工作、失败/超时、隐私或越权事件。记录每组 token、工具/API 实付费用、耗时及主持/复核人工分钟；无账单则费用记未知。每臂限 20 分钟，人工总预算 6 小时；先登记 token/调用上限再运行，触顶停止。

**决策阈值（人为选定，非经验事实）**：核查仅在至少 6/8 例最终实质错误不增、至少 3 例减少，且额外人工中位数≤10分钟时继续；交接至少 3/4 例验收成功并优于 A 至少 1 例才扩大。任一隐私/越权事件暂停；高置信错误背书须返工调查。成本超限、质量持平或样本不足均不据此开发。小样本只决定下一轮，不能推导总体成功率、付费意愿或市场规模。
