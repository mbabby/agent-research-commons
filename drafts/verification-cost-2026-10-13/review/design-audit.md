## Concerns and required interpretation

1. **Inspect-before-execute requirement is not explicit in the participant prompt.** Preregistration requires script inspection before execution, but participants may not read that protocol. The reproducible prompt only calls code an aid “to inspect”; it does not directly say to inspect before executing. Keep the freeze unchanged; check actual participant actions and disclose any violation. A future version should place the explicit requirement in the visible prompt. The reviewed script itself is safe for the frozen inputs.
2. **Setup has a narrower measured boundary than a casual reader may infer.** The administrative wrapper puts live task show/start before the experimental clock. Experimental setup/prompt/source/result work is included, while official workflow onboarding is excluded. State this whenever reporting cost; do not call it total end-to-end participant cost. Source/prompt reading before the timer, if any, must be separately disclosed from actual logs.
3. **No pure presentation treatment or useful causal ranking.** Extraction plus integrity-check execution enriches one arm; one concurrent run per condition leaves session variation, output verbosity, scheduler effects and model settings uncontrolled. Report an observed workflow comparison only. The fixed, designer-selected sample has known design bias, and source reading/script output may expose unsampled facts. Sample verdict coverage remains four units even when more text is seen.
4. **Cost equivalence needs substantive review.** Redo writes one endpoint; verifiers write sample plus full endpoints and ledgers. Their wall times include different reporting obligations. This protocol assesses those actual workflows, not an isolated cognitive verification cost. Full-stage costs include the sample, which must not be treated as an independent replicate. Quality must be checked before any equivalent-quality saving claim.
5. **No exact total author cost, marginal format cost or break-even.** Pre-timer author work is unknown and per-format labor cannot be separated from one shared construction session. Adding all measured preparation to a verifier is an upper allocation of measured shared preparation only, not an upper bound on real total labor. Review/coordinator/admin overhead remains additional unless observed. Null token and dollar fields cannot support monetary savings.
6. **Self-reported timestamps and procedural freezing need corroboration.** Matching hashes now does not establish when samples were frozen or when participants first saw materials. Check transcript/clock/operation evidence and immutable recorded sample hashes if available; do not infer temporal order from file names or final mtimes alone.
7. **Script integrity checks have deliberately bounded scope.** The script hashes the files listed by the manifest but does not validate metadata schema, allowed paths, commit equality, line bounds or semantic locator adequacy. Current frozen records were independently checked and valid. Do not market this as a general secure/reliable verification runner or execute unknown modified inputs merely because this instance passed.
