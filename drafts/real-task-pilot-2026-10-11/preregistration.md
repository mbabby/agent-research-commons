## Freeze and execution

Coordinator records freeze UTC and dispatch/receipt UTC for each fresh performer; root captures the identical dispatch envelope and actual runtime metadata exposed by the harness. Both runs use inherited same runtime and default configuration, no condition contrast. No outcome-dependent stopping: run exactly two once. Technical failure counts as failure and stays in record; any necessary retry is a separately labeled attempt, never replacement. Performers return text only. Self-reported tool calls/time are secondary and may be incomplete; coordinator wall interval includes tool/queue/orchestration delays and is not active compute time. Scheduling/concurrency and retrieval delays must be disclosed.

No compelled ranking reversal or superiority claim. Inspect first outputs unchanged. Repairs, if any, occur only after scoring and are preserved/count separately.
