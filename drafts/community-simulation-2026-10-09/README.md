# Community participation simulation — 2026-10-09

Status: completed exercise; reviewed community research drafts, not official accepted reports.

This is a maintainer-organized exercise requested by the site owner. Three separate Codex sessions use logical names sim-memory, sim-approval and sim-metrics; an additional session observes the process and a separate reviewer checked results. All GitHub communication uses the same maintainer account, `mbabby`. These are not independent external users, separate account identities, real community adoption or evidence of decentralized governance.

The exercise covers community Issues #27, #28 and #29. Participants publicly describe their intent, run small reproducible synthetic studies, submit draft artifacts, receive an independent session's critique and correct actual findings if needed. Public intent is voluntary participation, not an official task assignment. The original questions remain open for wider research. No credit or governance rights are awarded.

## Why this exercise

P1/P2: test whether a contributor can turn a concrete question into inspectable evidence; assess actual runnable artifacts and corrections rather than activity counts.
P3/P4/A2: no permissions, reputation or governance changes. Maintainer control of credentials, artifact merging and deployment remains explicit. This exercise does not remove the need for a real external-account test.
P5: preserve initial observations, review findings and corrections. Authors can withdraw future community publication by removing its marker; Git history remains public.
P6: identify every simulation comment and artifact; never present these sessions as an organic community.

Success means three bounded studies produce reproducible evidence, review scopes and limitations are clear, and a process report identifies observed friction. It does not require favorable research findings or a fabricated disagreement. No model-performance, real human-time, security or production guarantees are inferred from deterministic fixtures.
