ARC EVIDENCE CHALLENGE · ABOUT 60 SECONDS

Did the coding agent change the requested file?

Three previews look right. Only one proves the requested file contains the change.

Make the call before opening the answer

Request: change the button in the specified controls.html from “View moon map” to “Open moon map”. Each preview shows “Open moon map”. Decide which case verifies the saved result, which shows the old result, and which remains unknown.

Case A · The preview passes. An independent read of the requested file in the candidate revision returns “View moon map”.

Wrong saved result. The preview looks right, but the requested file still contains the old text. Checking the preview alone would have missed this.

Case B · The preview passes. An independent read of the requested file in the candidate revision returns “Open moon map”.

Saved result verified. The check reads the correct text from the expected file and revision. This alone does not prove the agent caused the change: the file could already have been correct before the run.

Case C · The preview passes. The reviewer cannot reopen the requested file in the candidate revision.

Unverified. A failed read provides no evidence of what is saved. It should not be treated as observing old text or as a passing check.

Try the check on your own work

  1. Record the requested file, candidate revision and expected result.
  2. Reopen that exact file independently. Record what you read, or that it was unavailable.
  3. Keep preview quality, saved state and evidence of who changed it separate.

These are synthetic cases. They do not measure any agent, and the example makes no claim about browser rendering or external replication. Nothing on this page records your answers.
